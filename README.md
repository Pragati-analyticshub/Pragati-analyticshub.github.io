# Pragati Gupta — BI & Analytics Portfolio

A responsive personal portfolio starter built with plain HTML and CSS for GitHub Pages.

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
2. Replace the generic LinkedIn URL with your profile URL.
3. Review every experience description and ensure it is accurate and safe to share publicly.
4. Confirm certification names and add official verification links where available.
5. Replace proposed project descriptions with completed work, screenshots, and demo/repository links as you build them. Do not claim outcomes or metrics you cannot substantiate.
6. Consider adding a PDF résumé once you have a public-ready version.

## Publish with GitHub Pages

1. Create or sign in to your GitHub account.
2. Create a new **public** repository named exactly `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
3. Upload `index.html`, `styles.css`, and `README.md` to the repository root (not inside a nested folder).
4. Open the repository's **Settings → Pages**.
5. Under the build/deployment section, select **Deploy from a branch**, choose `main` and `/ (root)`, then save if those options are shown.
6. Wait for the deployment to finish. Your site should appear at `https://YOUR-USERNAME.github.io/`.

## Local preview

Open `index.html` in a browser. For a more realistic local preview, use VS Code with a local static server extension. This site has no build step and no JavaScript dependency.
